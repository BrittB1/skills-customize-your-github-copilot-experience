# 📘 Assignment: File Handling and JSON

## 🎯 Objective

Learn how to read, write, and organize data using Python files and JSON. This assignment helps students practice working with real-world data formats and building scripts that save and reload information.

## 📝 Tasks

### 🛠️ Read and Parse a JSON File

#### Description
Create a Python script that loads data from a JSON file and displays the information in a readable format.

#### Requirements
Completed program should:

- Open a valid JSON file using Python.
- Load the data using the `json` module.
- Print or display the contents clearly.
- Handle missing or invalid JSON data gracefully.

### 🛠️ Save User Data to a File

#### Description
Write a script that collects information from the user and saves it to a JSON file.

#### Requirements
Completed program should:

- Prompt the user for a name, favorite color, and age.
- Store the values in a dictionary.
- Save the dictionary to a `.json` file.
- Confirm that the data was written successfully.

### 🛠️ Update Existing Data

#### Description
Build a small program that loads an existing JSON file, updates one value, and saves the changes back to disk.

#### Requirements
Completed program should:

- Read the current JSON file.
- Modify at least one field in the loaded data.
- Write the updated data back to the same file.
- Keep the file in valid JSON format after the update.

### 🛠️ Bonus Challenge: Create a Simple To-Do List

#### Description
Extend the project by storing a list of tasks in JSON and allowing the user to add or view tasks.

#### Requirements
Completed program should:

- Store a list of tasks in a JSON file.
- Add new tasks from user input.
- Display all tasks in a readable list.
- Keep the saved file organized and valid JSON.
